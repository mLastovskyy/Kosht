# Kosht

Личное приложение для учёта финансов на Android. «Кошт» — по-белорусски «средства, расходы».

## Возможности

- **Главная** — общий баланс (с эквивалентом в BYN для иностранной валюты), доходы и расходы за месяц, последние операции
- **Операции** — быстрый ввод с кастомной клавиатурой, категории, дата, заметки
- **Скан чеков** — фото чека (камера или галерея) распознаётся офлайн (Tesseract, русская модель): сумма, дата и магазин подставляются сами
- **История** — группировка по дням, поиск, фильтры, свайп-удаление с отменой
- **Статистика** — анимированные donut- и bar-диаграммы + календарь-теплокарта трат по дням
- **Кошелёк** — долги (кто кому и сколько, частичное погашение), накопления (журнал «отложил/снял»), ежемесячные платежи с обязательным подтверждением
- **Курсы валют** — официальные курсы НБРБ, суммы в чужой валюте дублируются в BYN
- **Уведомления** — вечернее напоминание записать траты, платежи к подтверждению, итоги недели (настраиваются)
- **Настройки** — тема, Material You, валюта, язык интерфейса (система/русский/английский)

## Технологии

- Kotlin + Jetpack Compose (Material 3), встроенный Kotlin AGP 9
- Room + Flow — реактивная локальная база (миграции v1→v3)
- DataStore Preferences — настройки; WorkManager — напоминания
- Navigation Compose, ViewModel, ручной DI-контейнер
- Tesseract OCR (офлайн), API НБРБ для курсов
- Кастомные графики на Canvas, анимации Compose

## Сборка

```bash
./gradlew :app:assembleRelease
```

APK: `app/build/outputs/apk/release/app-release.apk` (подписан debug-ключом для личной установки).

Требования: JDK 17+, Android SDK 37. Минимальная версия Android — 8.0 (API 26).
