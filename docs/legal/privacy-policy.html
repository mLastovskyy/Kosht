2. Основные понятия

  1. Персональные данные — любая информация, относящаяся к идентифицированному физическому лицу или физическому лицу, которое может быть идентифицировано.
  2. Субъект персональных данных (далее — Пользователь) — физическое лицо, создавшее учётную запись в Приложении.
  3. Обработка — любое действие с персональными данными: сбор, хранение, изменение, использование, передача, удаление.
  4. Учётная запись — создаваемая Пользователем запись, позволяющая хранить данные Приложения в облаке и синхронизировать их между устройствами.

3. Какие данные обрабатываются

  2. Приложение не содержит систем аналитики, рекламных сетей и сбора отчётов об ошибках.
  3. Оператор не принимает решений, порождающих юридические последствия для Пользователя, исключительно на основании автоматизированной обработки.

4. Основание обработки

  1. Обработка осуществляется на основании согласия Пользователя, выраженного при создании учётной записи путём проставления соответствующей отметки, — то есть посредством действия, однозначно подтверждающего его волю.
  2. Согласие является свободным: отказ от его предоставления не лишает возможности пользоваться Приложением без учётной записи.
  3. Согласие на получение рекламных и информационных рассылок запрашивается отдельно и не является условием создания учётной записи или доступа к функциям Приложения.
  4. Пользователь вправе в любое время и без объяснения причин отозвать любое из согласий в порядке, описанном в разделе 8.

5. Цели обработки

  1. Создание учётной записи, идентификация Пользователя при входе, подтверждение принадлежности адреса электронной почты и восстановление доступа к паролю.
  2. Хранение данных Приложения в облаке и их синхронизация между устройствами Пользователя.
  3. Направление сервисных сообщений, без которых услуга не может быть оказана: кода подтверждения адреса и кода восстановления пароля.
  4. Направление рекламных и информационных сообщений — только при наличии отдельного предварительного согласия.
  5. Рассмотрение обращений Пользователя и подтверждение исполнения требований законодательства о персональных данных.

7. Хранение и защита

  1. Данные хранятся до удаления учётной записи Пользователем либо до отзыва согласия. После удаления учётной записи данные Приложения, сведения о согласиях и обращениях удаляются без возможности восстановления.
  2. Сведения о согласиях хранятся в виде неизменяемого журнала: записи только добавляются, что позволяет подтвердить, когда и с какой редакцией документа согласился Пользователь.
  3. Применяемые меры защиты: передача данных исключительно по защищённому протоколу HTTPS; разграничение доступа на уровне строк базы данных, при котором записи одной учётной записи технически недоступны другой; хранение пароля в виде необратимого хеша; ограничение круга лиц, имеющих административный доступ.
  4. На устройстве данные Приложения хранятся в приватной области, недоступной другим приложениям, и удаляются вместе с Приложением.

8. Права Пользователя и порядок их реализации

  1. Пользователь вправе: получить информацию об обработке своих персональных данных и о лицах, которым они передавались; получить копию своих данных; требовать внесения изменений в неполные, устаревшие или неточные данные; отозвать согласие; требовать прекращения обработки и удаления данных; обжаловать действия Оператора в Национальном центре защиты персональных данных Республики Беларусь.
  2. Часть прав реализуется непосредственно в Приложении, без обращения к Оператору: «Настройки → Уведомления» позволяют отключить рассылку, «Настройки → Аккаунт» — полностью удалить учётную запись вместе со всеми данными. Копия данных предоставляется по заявлению в порядке, описанном ниже.
  3. Заявление также может быть направлено на адрес электронной почты, указанный в пункте 1.2. Заявление должно содержать фамилию, собственное имя, отчество (при наличии), адрес электронной почты учётной записи и излагаемую суть требования.
  4. Оператор рассматривает заявление и уведомляет о результате в пятнадцатидневный срок со дня его получения. Ответ направляется в той же форме, в которой поступило заявление, если в заявлении не указано иное.
  5. В предоставлении информации может быть отказано в случаях, предусмотренных законодательством; отказ доводится до Пользователя с указанием причины в тот же пятнадцатидневный срок.

9. Рекламные и информационные рассылки

  1. Рекламные сообщения направляются только при наличии предварительного согласия Пользователя, выраженного отдельной отметкой. По умолчанию такое согласие считается непредоставленным.
  2. Отказ от рекламной рассылки возможен в любой момент: переключателем в разделе «Настройки → Документы и согласия» либо по ссылке отказа, содержащейся в каждом рекламном письме. Ссылка действует без входа в учётную запись.
  3. Отказ от рекламной рассылки не влияет на возможность пользоваться Приложением и не прекращает направление сервисных сообщений, указанных в пункте 5.3.
  4. Требование о прекращении рассылки исполняется незамедлительно.

10. Несовершеннолетние

  1. Приложение не предназначено для лиц младше 16 лет. Оператор не осуществляет целенаправленный сбор данных таких лиц. Если станет известно, что учётная запись создана лицом младше 16 лет без согласия законного представителя, она будет удалена.

11. Изменение Политики

  1. Оператор вправе изменять Политику. Новая редакция размещается по адресам, указанным в пункте 1.4, с указанием номера редакции и даты.
  2. Если изменения затрагивают объём обрабатываемых данных или цели обработки, согласие запрашивается заново.
