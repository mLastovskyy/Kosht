## Шаг 1. Собрать артефакт ⏳

```powershell
.\gradlew.bat :app:bundleRelease
```

Результат: `app/build/outputs/bundle/release/kosht-<версия>-release.aab` (~20 МБ,
пользователь скачает меньше — Play разбивает бандл по архитектурам).

Проверить, что подписан правильным ключом:

```powershell
& "$env:LOCALAPPDATA\Android\Sdk\build-tools\<версия>\apksigner.bat" verify --print-certs `
  app\build\outputs\apk\release\kosht-*-release.apk
```

Должно вывести `CN=Maksim Lastovsky, OU=Kosht, ...`, а не `CN=Android Debug`.

## Шаг 2. Захостить политику конфиденциальности ⏳

Магазины требуют публичный URL. Быстрее всего — GitHub Pages:

1. GitHub → репозиторий → **Settings → Pages**.
2. Source: `Deploy from a branch`, ветка `master`, папка `/docs`.
3. Через пару минут политика будет по адресу
   `https://mlastovskyy.github.io/Kosht/privacy.html` — этот URL и вставляй в анкеты.

## Шаг 3. Секреты для CI (по желанию) ⏳

Чтобы GitHub Actions собирал **подписанные** релизы, добавь секреты:
репозиторий → Settings → Secrets and variables → Actions → New repository secret.

| Имя секрета | Значение |
|---|---|
| `KOSHT_KEYSTORE_BASE64` | результат команды ниже |
| `KOSHT_KEY_ALIAS` | `kosht` |
| `KOSHT_STORE_PASSWORD` | из `.env` |
| `KOSHT_KEY_PASSWORD` | из `.env` (тот же) |

```powershell
[Convert]::ToBase64String([IO.File]::ReadAllBytes("kosht-release.jks")) | Set-Clipboard
```

Без секретов CI продолжит работать — просто подпишет debug-ключом (годится для
установки на свой телефон, но не для магазинов).

## Шаг 4. Google Play ⏳

1. Регистрация: <https://play.google.com/console> — разовый взнос **$25**, нужна карта
   и подтверждение личности (для физлиц — документ + адрес).
2. **Важно:** личным аккаунтам, созданным после ноября 2023, Google требует
   **закрытое тестирование: 12 тестировщиков минимум, непрерывно 14 дней**, и только
   потом открывает продакшен. Планируй заранее — собери 12 человек с Google-аккаунтами.
3. Создай приложение → заполни:
   - Название, краткое и полное описание — из `docs/store/listing-ru.md` (и EN-версию
     как второй язык).
   - Иконка `docs/store/icon-512.png`, баннер `docs/store/feature-1024x500.png`,
     минимум 2 скриншота телефона из `screenshots/`.
   - **Data safety**: «Не собираются и не передаются никакие данные». Приложение
     действительно ничего не отправляет.
   - Контент-рейтинг: анкета → получится 3+ / Everyone.
   - Целевая аудитория: 18+ (финансовое приложение — так меньше требований).
   - Privacy Policy URL из шага 2.
4. Release → Testing → **Closed testing** → создай трек, загрузи `.aab`, добавь
   тестировщиков (список email или Google-группа).
5. Через 14 дней непрерывного тестирования → Production → отправка на проверку
   (обычно 1–7 дней).
6. Обновления: пуш в `master` → CI соберёт новый `.aab` с бо́льшим `versionCode` →
   загрузить в консоль.

## Шаг 5. Huawei AppGallery ⏳

1. Регистрация: <https://developer.huawei.com> → AppGallery Connect. Для физлица
   **бесплатно**, нужна верификация паспортом (1–2 дня).
2. «Мои приложения» → «Новое приложение» → Android, категория «Финансы».
3. Загрузи тот же `.aab` (AppGallery принимает и APK), заполни описание из
   `docs/store/listing-ru.md`, скриншоты, Privacy Policy URL.
4. Требований к предварительному тестированию нет — проверка обычно 1–3 дня.
5. Kosht не использует Google-сервисы, так что на устройствах без GMS работает
   полностью.

## Шаг 6. После публикации

- Обнови ссылку на стор в `README.md`.
- Проверка обновлений внутри приложения (Настройки → Версия) продолжит указывать на
  GitHub Releases — это удобно для бета-сборок в обход магазинов.
- Каждый пуш в `master` поднимает `versionCode` автоматически: он равен числу
  коммитов, магазины требуют строго возрастающее значение.
